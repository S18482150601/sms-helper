卡密验证

本工具需卡号 + 卡密才能使用。请将购买所得的卡号与卡密填入下方。

可选授权时长：1天 / 7天 / 15天 / 1个月 / 3个月 / 6个月 / 1年（由卡号自动识别）

提示：授权记录保存在本浏览器本地，清除浏览器数据会丢失授权（需重新输入卡密，重新计时）。请勿在微信 / QQ 内置浏览器中打开本页。

1. 上传Excel表格

表格第一行为表头，必须包含【手机号】列，支持姓名等自定义字段。支持 .xlsx / .xls / .csv。

2. 短信模板

示例：尊敬的{姓名}，您好！通知内容……（用 {列名} 读取表格对应列的内容）

3. 发送控制

⚠️【无间隔极速模式】拉起短信页面立刻标记记录，无等待、无延时！只要打开短信编辑页，无论是否发送，直接计入发送日志！适合批量唤起短信，事后人工核对。网页无法感知短信是否真实发送状态，也不能自动点击“发送”。
