短信助手 · 操作指引

电脑端负责发，手机端负责操作 · 同一 Wi-Fi 即可

先看懂这张图

手机浏览器 / 桌面 App→ 同一个 Wi-Fi→ 电脑上的服务 :8787→ 阿里云 / 腾讯云短信

手机不装软件、不填密钥。密钥只存在电脑上，手机只负责选人、点按钮。

电脑关机或断网，手机就打不开；想 24 小时可用需要放到云服务器。

一、电脑端（只做一次）

1. 安装 Node.js

1

浏览器打开 nodejs.org，下载 LTS 版（Windows 选 .msi）。

2

双击安装，一路「下一步」。安装界面里如果出现 Add to PATH 的勾选项，保持勾选。

3

装完验证：按 Win + R 输入 cmd 回车，输入 node -v，出现 v20.x.x 之类的版本号即成功。

2. 启动服务

1

进入 server 文件夹，双击 启动服务.bat。

2

黑色窗口出现下面内容就成功了，这个窗口不要关（关掉服务就停）：

  短信助手本地服务已启动
  通道：mock（模拟，不真发）
  手机打开：   http://192.168.1.8:8787/
3

首次启动如果弹出 Windows 防火墙提示，勾选「专用网络」并点 允许访问。否则手机连不上。

窗口里那个 http://192.168.x.x:8787/ 就是手机要打开的地址，先记下来。换了 Wi-Fi 或重启路由器，IP 可能变，重新看窗口即可。

3. 填真实短信通道（要真发才需要）

首次启动会在 server 目录生成 config.json（或从 config.example.json 复制）。用记事本打开，改 provider 和对应段：

通道必填配置
mock默认值，只走流程、不会真发短信。用来熟悉界面。
aliyunaccessKeyId、accessKeySecret、signName（签名）、templateCode（模板 CODE，如 SMS_123456）
tencentsecretId、secretKey、sdkAppId、signName、templateId
custom任意 HTTP 网关：url、请求头、body 模板、成功判定字段
{
  "port": 8787,
  "provider": "mock",
  "aliyun": {
    "accessKeyId": "你的KeyId",
    "accessKeySecret": "你的KeySecret",
    "signName": "已审核的签名",
    "templateCode": "SMS_123456789"
  }
}
改完必须重启服务：关掉黑窗口，重新双击 启动服务.bat。签名和模板必须是在阿里云/腾讯云审核通过的，否则平台直接拒发。

4. 电脑端常见报错

现象处理
'node' 不是内部或外部命令安装时没勾 PATH。重装 Node.js，或关掉窗口重新启动 启动服务.bat。
EADDRINUSE8787 端口被占用。把 config.json 里 "port" 改成 8788，重启，手机地址同步改。
窗口一闪就消失Node 没装好。先在 cmd 里跑 node -v 确认。
关掉窗口后手机打不开正常。服务必须保持运行，可最小化但别关。

二、手机端（每次使用）

1. 打开页面

1

手机连上和电脑同一个 Wi-Fi（不能用流量，不能连访客网络）。

2

浏览器输入电脑窗口里那个地址，如 http://192.168.1.8:8787。

3

打开后页面顶部应显示「已连接」类提示。若打不开，先看第 4 节排查。

2. 加到桌面（当 App 用，可选）

  • iPhone：Safari 打开 → 底部 分享 ⤴ → 添加到主屏幕
  • 安卓：Chrome 打开 → 右上 ⋮ → 安装应用 / 添加到主屏幕
桌面图标是全屏运行，没有地址栏。注意：装成 App 后数据是独立存储，之前在浏览器里存的联系人不在这里，需重新导入一次。

3. 导入联系人

1

点「选择文件」，选 Excel（.xlsx）或 CSV。企查查、天眼查导出的原始表格直接传，不用改表头。

2

系统自动识别：姓名、手机号、公司/备注。表头写「电话」「联系人」「企业名称」也能认，无表头也能认。

3

看「姓名列」下拉框括号里显示的列名，确认取对了；不对就手动选一列。

4

上传后会显示预览：发给第一条的完整内容，{姓名} 有没有替换一眼可见。

4. 写模板

占位符替换成
{姓名}联系人姓名（也支持 {名字} {法人} {客户}）
{公司}公司 / 备注列
{电话}手机号

全角 ｛姓名｝、带空格 { 姓名 } 都能识别。

5. 批量发送（单次最多 1000 条）

1

第 4 张卡填接口地址（通常已自动填好，就是当前网址），点 检查通道。

2

显示「已连接：阿里云」或「模拟」即正常；显示「连不上服务」见第 4 节。

3

填模板 CODE（如 SMS_123456789）和变量名（默认 name，必须与平台模板里的变量一致）。

4

表格里勾选联系人（可全选），点 一键批量发送。进度条实时显示「已发送 / 总数 / 失败数」。

5

完成后点 导出通道发送结果，得到 CSV：每个号码的成功/失败与失败原因。

重复号码自动跳过，+86 前缀自动归一化，无效号码标记「号码不合法」不发。单条内容由模板决定，这正是正规通道和群发的区别。

6. 其他功能

  • 逐条唤起：免费方式，一条条打开系统短信界面，需手工点发送，适合少量个性化沟通。
  • 连续拨号：挂断后自动拨下一通，中间有 1.5 秒缓冲，随时可暂停/继续。
  • 客户联系表：单独页面，管理名单、批量导入、拨号与短信，和主页面数据互通规则见页面提示。

三、手机连不上怎么排查

现象原因与处理
一直转圈 / 打不开手机和电脑不在同一 Wi-Fi；或电脑黑窗口被关了。确认窗口还在、手机连的是同一路由器。
提示「拒绝连接」防火墙拦了。控制面板 → Windows Defender 防火墙 → 允许应用通过 → 勾上 Node.js 的专用网络。
昨天能用今天不行电脑 IP 变了。重新看黑窗口里的地址，用新的。
页面能开但「检查通道」失败接口地址填错。点一下地址框，应该是 http://电脑IP:8787，不带多余路径。
发送全失败，提示签名/模板平台侧未通过审核或模板变量不匹配。到服务商控制台核对签名、模板 CODE、变量名。
网络正常但仍失败公司网络可能禁了手机访问内网。换手机热点给电脑，电脑连热点后重看地址。

四、必须知道的合规红线

  • 营销短信必须事先获得接收人同意，内容需带退订方式，否则违反《广告法》《通信短信息服务管理规定》。
  • 签名与模板需企业实名 + 平台审核，审核通过才能发；贷款、金融类模板审核极严。
  • 「银行白名单 / 免审核 / 保证额度」这类表述属虚假宣传，被投诉会被运营商封端口、平台封账号。
  • 不受理、不协助任何绕过系统发送限制的做法（网页无法静默群发，这是操作系统安全限制）。
建议只对已授权客户做回访通知。批量营销一旦被投诉，损失的是你自己的号码和账号。

五、一页速查

1电脑双击 启动服务.bat → 记住窗口里的 http://192.168.x.x:8787

2手机连同一 Wi-Fi → 浏览器打开该地址

3上传表格 → 确认姓名列 → 看预览

4点 检查通道 → 填模板 CODE 与变量名

5勾选联系人 → 一键批量发送 → 导出结果

注意电脑关机 = 手机端不可用；真实发送需先在平台通过签名与模板审核。
