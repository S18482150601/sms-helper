# 用安卓手机当发送端

电脑用数据线连安卓手机，逐条调用手机系统短信接口，用手机里的 SIM 卡发送。不需要云平台、不需要密钥。

> 只适合**已同意接收**的客户，且必须控制数量。运营商对单卡有频次和内容监控，连续群发或含敏感词会被直接封卡。

## 一次性准备

### 1. 手机打开 USB 调试

1. 设置 → 关于手机 → 连点「版本号」7 次，出现“已进入开发者模式”。
2. 设置 → 系统 → 开发者选项 → 打开 **USB 调试**。
3. 数据线连电脑，手机弹窗点 **允许**（勾选“始终允许”并确定）。

### 2. 电脑装 adb

1. 下载 Android SDK Platform-Tools（搜 `platform-tools` 官网下载）。
2. 解压到一个固定目录，例如 `D:\platform-tools`。
3. 在该目录的地址栏输入 `cmd` 回车，执行：

```
adb devices
```

看到一行 `<序列号>   device` 就成功了。若是 `unauthorized`，解锁手机重新点允许。

## 每次使用

### 1. 网页导出清单

在短信助手页面上传表格、写好模板，勾选联系人（不勾选则导出全部），点 **「导出待发清单（JSON）」**，把下载的 `待发清单_xxx.json` 放到本目录。

### 2. 先预览

```
node send.js --jobs 待发清单_xxx.json --dry-run
```

逐条打印号码和内容，不发出去，用来自查模板有没有替换对。

### 3. 正式发送

```
node send.js --jobs 待发清单_xxx.json
```

- 默认每条间隔 3 秒，建议保持 `--delay 3000` 或更大。
- 已发过的号码记在 `sent-log.json`，重跑会自动跳过。
- 结果写到 `logs/result-时间.csv`，可用 Excel 打开。

### 4. 如果提示 SecurityException / Permission denied

安卓 10 以上经常不允许电脑直接调用短信接口，改用半自动：

```
node send.js --jobs 待发清单_xxx.json --manual
```

手机屏幕会逐条弹出短信编辑页并填好号码和内容，你点一下“发送”，电脑继续下一条。

## 常用参数

| 参数 | 作用 |
| --- | --- |
| `--dry-run` | 只预览，不发送 |
| `--count 20` | 本次只发前 20 条 |
| `--delay 5000` | 每条间隔 5 秒 |
| `--manual` | 打开发送界面，人工点发送 |
| `--force` | 忽略已发记录，重发 |
| `--serial 序列号` | 连接了多台设备时指定 |
| `--adb D:\platform-tools\adb.exe` | adb 不在 PATH 时指定路径 |

## 常见问题

- **没有检测到设备**：换一根能传数据的线；USB 调试是否真的开了；手机弹窗是否点了允许。
- **显示已提交但对方没收到**：手机可能欠费、无信号，或被运营商拦截内容。查手机短信中心号码和话费。
- **发到一半卡住**：`Ctrl + C` 停止，重新运行会从没发过的号码继续。
- **安卓版本太新一直失败**：只能用 `--manual`，或改用云短信平台。
